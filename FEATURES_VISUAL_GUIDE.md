## 10. USER EXPERIENCE FLOW

### Profile Editing Flow:
```
User on Dashboard
       │
       ▼
   [Click 👤 Profile button]
       │
       ▼
[Profile modal opens with current data]
       │
       ├─ Edit Name ──────┐
       │ Edit Phone ──────┤─ User makes changes
       │ Edit Bio ────────┤
       │ Edit Location ───┘
       │
       ▼
[Click "Save Changes"]
       │
       ▼
[Data sent to backend API]
       │
       ▼
[Profile updated in MongoDB]
       │
       ▼
[Success message shown]
       │
       ▼
[Modal closes, navbar updates with new name]
```

### Language Switching Flow:
```
User viewing Dashboard (English)
       │
       ▼
[Click language dropdown: English ▼]
       │
       ▼
[Select हिंदी]
       │
       ▼
[JavaScript: updateUILanguage('hi')]
       │
       ▼
[All elements with data-i18n update]
       │
       ▼
[Language saved to localStorage]
       │
       ▼
[Page reloads to apply all changes]
       │
       ▼
[Dashboard now in Hindi हिंदी]
```

## 11. DATA FLOW: AI CHARTS

```
User clicks "Run Prediction"
       │
       ▼
[Send 11 spectral bands to backend]
       │
       ▼
[Python AI model predicts SOC %]
       │
       ▼
[Backend returns: soc, confidence, credits, formula]
       │
       ▼
[Store prediction in window.predictionHistory]
       │
       ▼
[Call createAIPredictionCharts(history)]
       │
       ├─► Chart 1: Scatter (SOC vs Confidence)
       │
       ├─► Chart 2: Bar (Credits by Depth)
       │
       ├─► Chart 3: Line (Timeline History)
       │
       └─► Insight Card with calculations
       │
       ▼
[All 3 charts render with Chart.js]
       │
       ▼
[User sees complete analytics dashboard]
```
